## 📖 プロジェクト概要

**インタラクティブAIプロンプト・ビルダー**は、AI画像生成のプロンプトを、ブラウザのサイドパネル上で「**日本語の直感**」と「**英語の正確性**」を両立させながら構築・管理するChrome拡張機能です。

### コンセプト

日本語で表示されたキーワードを選択するだけで高品質な英語プロンプトを構築できる「**ビルダー機能**」と、構築したプロンプトを日本語で確認・編集し、即座に英語原文へ逆翻訳反映させる「**インタラクティブ翻訳機能**」を完全に統合します。

「**自動保存**」「**履歴保存**」機能も搭載し、ユーザーの試行錯誤とプロンプト資産の蓄積を強力にサポートします。

---

## 🎯 主な機能

### 機能A：プロンプト構築＆双方向翻訳インターフェース

プロンプトを構築し、編集するメインの作業エリアです。

#### ① 原文（ポジティブ・プロンプト）エリア

AIに渡す**英語のプロンプト**が構築されるテキストエリア。

**例**: `masterpiece, best quality, 1girl, gothic`

> このエリアは、従来の「ポジティブ・プロンプト・エリア」と「翻訳の原文エリア」を統合したエリアです。

#### ② 翻訳結果（日本語確認）エリア

上記①の原文エリアの内容が、**リアルタイムで日本語に自動翻訳**されて表示されるエリア。

**例**: `傑作、最高品質、一人の女の子、ゴシック風`

#### ③ 双方向リアルタイム翻訳（インタラクティブ編集機能）

**🔥 核心機能**: 英語⇔日本語の双方向翻訳により、どちらの言語からでもプロンプトを編集可能

**英語→日本語**:
- ユーザーが①の原文エリアを編集（またはキーワードセレクターで追加）
- 即座に②の翻訳結果（日本語）が更新される

**日本語→英語（逆翻訳）**:
- ユーザーが②の翻訳結果（日本語）エリアを編集
  - 例: 「ゴシック風」→「サイバーパンク風」に修正
- その内容が即座に逆翻訳され、①の原文（英語）エリアに反映
  - 例: `gothic` → `cyberpunk` に置き換わる

> これにより、ユーザーは**使い慣れた日本語でプロンプトのニュアンスを微調整**できます。

#### ④ キーワード・セレクター（日本語UI・英語出力）

**🔥 核心機能**: 日本語でキーワードを選ぶと、英語プロンプトが自動構築される

**カテゴリ例**:
- 品質
- キャラクター
- 画風
- 構図
- 服装
- 外見

**表示**: 各キーワードボタンは**日本語で表示**
- 例: `[傑作]`, `[90年代風]`, `[上からのアングル]`

**動作**: 日本語ボタンをクリック
- 対応する**英語のキーワード**が、カンマ区切りで①の原文（英語）エリアの末尾に追記される
- 例: `[傑作]` クリック → `masterpiece` が追加

#### ⑤ ネガティブ・プロンプト エリア

**除外したい要素（英語）** を入力するテキストエリア。

**例**: `low quality, worst quality, nsfw`

- キーワード・セレクターは、このネガティブ・プロンプト・エリアに対してもキーワードを追加可能
  - 例: 「ネガティブに追加」モードで切り替え

> **将来的な拡張**: ネガティブエリアにも②③と同様の「双方向翻訳機能」を搭載可能

---

### 機能B：自動保存＆履歴管理

編集中のデータを保護し、過去の資産を再利用する機能です。

#### ⑥ 自動保存（セッション復元）機能

**自動保存の対象**:
- ①の原文（英語）エリア
- ⑤のネガティブ・プロンプト（英語）エリア

**動作**:
- 編集のたびに自動で**Chrome Storageに保存**
- ブラウザを閉じても、次回サイドパネル起動時に**作業内容が復元**される

#### ⑦ 履歴保存（スナップショット）機能

**保存方法**:
- 「**履歴に保存**」ボタンを押す
- その時点の①原文（英語）と⑤ネガティブ（英語）のセットを保存
- **名前（または日時）** をつけて意図的に保存

**復元方法**:
- 「履歴」タブから過去に保存したプロンプトセットを一覧表示
- **クリック一つで**現在の編集エリアに読み込む（復元）

## 🎨 ユーザー体験フロー

この仕様により、以下のワークフローが実現されます：

```
1. 日本語でキーワードを選ぶ（機能A-④）
   ↓
2. 英語プロンプトが自動構築される（機能A-①）
   ↓
3. 日本語翻訳で内容を確認（機能A-②）
   ↓
4. 日本語で微調整する（機能A-③）
   ↓
5. 自動保存される（機能B-⑥）
   ↓
6. 気に入ったものを履歴に保存（機能B-⑦）
```

## 🛠️ 技術要件

### 開発環境

- **フレームワーク**: React + TypeScript
- **ビルドツール**: Vite
- **プラットフォーム**: Chrome拡張機能（Manifest V3）
- **UI配置**: サイドパネル
- **ストレージ**: Chrome Storage API
- **翻訳API**: Google Apps Script（Google翻訳API経由）

### 型安全性の要求

> **🔴 重要**: `any`型の使用は一切禁止

以下の型を厳格に定義する必要があります：

- `Keyword` - 日本語表示（ja）と英語（en）を持つ
- `KeywordCategory` - カテゴリ名とKeywordの配列を持つ
- `HistoryEntry` - ID、positiveプロンプト、negativeプロンプト、保存日時を持つ
- `PromptState` - 現在のpositiveとnegativeの文字列を持つ状態の型

詳細は [型定義設計](02-types-design.md) を参照。
